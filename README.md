# vibecraftstudios.de

Statische Website auf GitHub Pages. Keine externen Ressourcen: Schriften, three.js, Artist-Artworks und kurze Audio-Previews liegen lokal im Repo.

- `index.html`, `impressum.html`, `datenschutz.html`, `style.css`
- `src/main.js`, `src/beats.js`: 3D Collector's Sleeves, farbige Spezial-Vinyls, Genre-Umgebungen und Beat-Synced Audio Previews (three.js). Nach Änderungen bauen: `npm install` und `npm run build` → `js/app.js`
- `assets/img/`: WebP-Cover (`1024×1024`) und Vinyl-Etiketten (`512×512`) der virtuellen Artists
- `assets/audio/`: 17–18s MP3-Hörproben (128 kbps) der aktuellen Releases
- Schriften: Big Shoulders Display, IBM Plex Mono (SIL Open Font License, siehe `fonts/`)
