# vibecraftstudios.de

Statische Website auf GitHub Pages. Keine externen Ressourcen: Schriften, three.js und Bilder liegen im Repo.

- `index.html`, `impressum.html`, `datenschutz.html`, `style.css`
- `src/main.js`: 3D-Schallplatte (three.js). Nach Änderungen bauen: `npm install` und `npm run build` → `js/app.js`
- Schriften: Big Shoulders Display, IBM Plex Mono (SIL Open Font License, siehe `fonts/`)
